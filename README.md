# team-store

Учебный командный проект RS School: интернет-магазин компьютерных комплектующих.
Каталог с поиском, фильтрами и сортировкой, корзина с расчётом стоимости и промокодом.

Команда: [Al-E-xXx](https://github.com/Al-E-xXx) и напарник (состав и вклад — на странице «О нас» в приложении).

- Доска задач: https://github.com/users/Al-E-xXx/projects/1
- Устройство проекта и правила команды: [ARCHITECTURE.md](ARCHITECTURE.md)
- Опубликованное приложение: ссылка появится после задачи #13 (публикация)

## Запуск

Требуется Node.js ≥ 22.

```bash
npm ci
npm run dev       # разработка
npm run build     # сборка
npm test          # тесты (Vitest)
```
